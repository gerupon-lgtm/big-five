# T-005 Result UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build accessible 20-question preview and 50-question result screens that render all five factors, the selected cat, three palettes, six fragrance suggestions, historical text snapshots, and documented fallbacks without changing diagnostic output.

> **Persistence correction (2026-07-26):** Task 7の旧記述より、要件8.4・8.5と`docs/data-model.md`、`docs/processing-design.md`の確定契約を優先する。`preview20`保存では追加回答用ProgressRecordを保持し、`detail50`完答ではResultSnapshot保存成否にかかわらず生回答を破棄する。ResultSnapshot保存成功時は追加とProgressRecord削除を同一StorageEnvelope書込みで行う。

**Architecture:** Keep scoring and classification in the existing domain layer. Consume the approved Q-006 content composer, Q-012 character manifest/loader, and Q-013 presentation selector through an exact result view model; render it with small presentation modules. Browser APIs and image loading remain injected boundaries so DOM, Canvas, image, and share failures cannot remove the text result.

**Tech Stack:** HTML, CSS, JavaScript ES Modules, Canvas 2D, browser APIs, Node.js `node:test`

## Global Constraints

- Dependency direction remains `presentation -> domain <- infrastructure`.
- The normal build performs no external network requests and keeps `connect-src 'none'`.
- Twenty-question `continueHidden` must not create or display a result model.
- Classification uses `rawMean`; display uses the existing 0–100 integer only.
- Both modes show all five factors in `factor-order-v1`.
- The factor explanation is an HTML button/region interaction, not Canvas-only.
- The 20-question preview suppresses detailed scene reflections and action hints.
- The 50-question result preserves the rendered text order supplied by Q-006.
- Only the selected character image is lazily requested.
- Character, Canvas, Web Share, PNG, and Clipboard failures retain selectable text.
- Palette changes update `selectedPaletteId` and card appearance only.
- Three palettes appear in standard, alternative 1, alternative 2 order.
- Fragrance scenes appear as pause, reset, quiet-focus with two candidates each.
- Character assets are never cropped or recolored.
- Use no runtime framework, analytics library, or external font dependency.
- Run `npm.cmd test` and `npm.cmd run check` before every completion claim.

```js
const PREVIEW_ALLOWED_SECTIONS = new Set([
  "titleSubtitle",
  "titleReason",
  "observation",
]);

export function createResultViewModel(input) {
  validateInput(input);
  const preview = input.mode === "preview20";
  if (preview && input.result.renderedTexts.some(
    ({ section }) => !PREVIEW_ALLOWED_SECTIONS.has(section),
  )) {
    throw new TypeError("RESULT_VIEW_MODEL_INVALID");
  }
  const subtitle = findUniqueText(input.result.renderedTexts, "titleSubtitle");
  const reason = findUniqueText(input.result.renderedTexts, "titleReason");
  return deepFreeze({
    mode: input.mode,
    heading: preview ? "20問簡易プレビュー" : "50問詳細結果",
    title: {
      titleId: input.profile.titleId,
      label: input.profile.label,
      subtitle: subtitle.text,
      reason: reason.text,
      notice:
        "本アプリ独自のプロフィール表現であり、心理学上の正式タイプではありません。",
    },
    factors: input.factorDefinitions.map((definition, index) => ({
      factorId: definition.id,
      displayName: definition.displayName,
      displayScore: input.result.factors[index].displayScore,
      description: definition.description,
    })),
    renderedTexts: input.result.renderedTexts.map((record) => ({ ...record })),
    boundaryMessages: createBoundaryMessages(input.result.boundaryFlags),
    character: { ...input.character },
    presentation: clonePresentation(input.presentation),
    resultTextVersion: input.resultTextVersion,
  });
}
```
