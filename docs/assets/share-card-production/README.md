## 対象

- タスク: T-007、T-008C（共有追補）
- 機能: F-011、F-012、F-013、F-018
- カード: 1080×1800 PNG（3:5）
- 縦構成イメージ承認日: 2026-07-31
- 最終リース`kokoro-wreath-v2.png`の採用承認日: 2026-08-02
- 実画像確認: 2026-08-02に標準、籠と木の実、手帳と札の猫3体で実Canvas合成し、共通の円弧形状、背面合成、下端追従、上下中央の開放、基線と枝葉の接続、透過縁を確認

F-013は、20問プレビュー完了時にResultSnapshotを残して対応ProgressRecordを削除し、共有可能な完了状態を確定する範囲だけで関係する。PNG Blob／Object URLの生成・再利用・解放はF-011／F-012の責務であり、F-013へ分類しない。

## 品質方針

- 完成カードや低解像度SVGをラスタライズした素材は使わない。リースは承認済みの高解像度透過PNGを原本として使い、実行時にSVGから変換しない。
- 猫と香り画は透過画像の縦横比を維持し、`contain`相当で描画してトリミングしない。
- 猫・香り画・リースはローカルの高解像度透過ラスタアセットを使う。白い円形カバーまたは透明を失わせる背景を追加せず、リースは猫の背面に合成して顔・胴体・尻尾を隠さない。
- 香り画は短辺800px以上とし、alpha、透明四隅、透明・不透明画素の共存、キー色の残存なしをテストする。
- プレビュー、Web Share、PNG保存は同一の1080×1800 PNG Blobを使い、表示とダウンロードの差を作らない。Canvasまたは共有APIが失敗しても、テキストコピーまたは選択可能テキストの代替を維持する。
- リース素材だけの読込失敗ではカード生成を止めず、称号、猫、因子、アロマ、共有テキストを維持する。
- 生成元の見た目を変更する場合は、素材版またはカードテンプレート版を更新し、台帳、テスト、実ブラウザ確認を同時に更新する。
