## 品質方針

- 完成カードや低解像度SVGをラスタライズした素材は使わない。
- 猫と香り画は透過画像の縦横比を維持し、`contain`相当で描画してトリミングしない。
- 猫・香り画はローカルの高解像度透過ラスタアセットを原寸品質で使う。SVGや完成カードをラスタライズせず、白い円形カバーまたは透明を失わせる背景を追加しない。v2の植物枝は猫の顔・胴体・尻尾を隠さない。
- 香り画は短辺800px以上とし、alpha、透明四隅、透明・不透明画素の共存、キー色の残存なしをテストする。
- プレビュー、Web Share、PNG保存は同一の1080×1800 PNG Blobを使い、表示とダウンロードの差を作らない。Canvasまたは共有APIが失敗しても、テキストコピーまたは選択可能テキストの代替を維持する。
- 生成元の見た目を変更する場合は、素材版またはカードテンプレート版を更新し、台帳、テスト、実ブラウザ確認を同時に更新する。
