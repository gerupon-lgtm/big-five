# Q-012 再利用コンポーネント

承認済みキャラクター画像から、別の構図・演出・制作参照へ再利用するための透過PNGを保管する。

## 保管規則

- タイトル単位のディレクトリを作り、`{componentId}-v{major}.png`で版管理する。
- 背景は透明とし、四隅のalphaは0、被写体を切らない余白を持たせる。
- 縦横比を維持して利用し、無断でトリミング・引き伸ばし・猫や首輪の再配色をしない。
- 見た目を変更する場合は既存ファイルを上書きせず、`v2`以降を追加する。
- 各ディレクトリの`manifest.json`へ寸法、byteLength、SHA-256、利用区分を記録する。

## 利用区分

- `direct-overlay`: 透過素材としてそのまま拡大縮小・配置できる。
- `pose-master`: 猫のポーズ・毛柄・体格を維持する制作参照。小物を合成する場合は接触部を人手確認する。
- `style-reference`: 意匠の正典。猫の姿勢に合わせた変形・遮蔽処理が必要なため、機械的な重ね合わせだけで完成扱いにしない。

最終キャラクター画像は引き続き`source-png/`を正典とし、コンポーネントから再構成した画像もQ-012のart/anatomy/technical reviewを通す。
