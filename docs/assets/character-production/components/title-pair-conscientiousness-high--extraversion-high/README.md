# 刻限に集う交流者：再利用パーツ

対象タイトルは`title-pair-conscientiousness-high--extraversion-high`。候補画像は

## 収録物

- `cat-base-v1.png`: 首輪・カード・時計を外し、隠れていた口元と首元を補完した歩行猫。`pose-master`。
- `wall-clock-v1.png`: 壁付け金具、フック、吊り輪、時計を一体化した透過小物。`direct-overlay`。
- `invitation-card-v1.png`: 無地の生成り色カード。文字・記号・影なし。`direct-overlay`。
- `collar-v1.png`: 赤い唐草模様、金具、短い余り部分、球形の鈴を含む首輪正典。`style-reference`。

## 再利用時の注意

- 時計とカードは縦横比を維持したまま配置できる。
- 猫本体へカードや首輪を付ける場合、口・ひげ・首毛・前脚との前後関係を描き直し、接触部を人手確認する。
- 首輪は姿勢ごとに遠近と遮蔽が変わるため、正典参照として使う。完成画像へそのまま引き伸ばして貼らない。
- この4点は新規構図へ再利用できるが、既存候補画像をピクセル単位で逆合成するためのレイヤーではない。
- 完成画像は猫1体、1〜2小物、無背景、画像内文字なし、首輪の正典構造を再確認する。
