# result-text-v2 行動ヒント限定レビュー

## 目的

2026-07-28に承認されたE-1〜E-5／F-1〜F-5を全体的に作り直さず、
15件の`actionHint`だけを`result-text-v2`移行前に再確認する。

`result-text-v1`の本文と承認記録は変更しない。この文書の判定は、
「反対側の傾向へ矯正せず、その傾向に合う活かし方・過ごし方・判断を
見つける」という`result-text-v2`の移行基準である。

## 確認記録

- 対象: E-1〜E-5／F-1〜F-5の`actionHint`全15件
- 状態: E/F/TR縦断レビュー後の`result-text-v2`移行文としてプロジェクトオーナー確認済み
- 確認日: 2026-07-29
- 縦断レビュー: `docs/research/2026-07-29-result-v2-cross-sectional-copy-review.md`
- 注意: `result-text-v1`の本文と承認記録は変更せず、`result-text-v2`全体のContent Approvalを示すものではない。

## 判定基準

- high／middle／lowを善悪や改善段階として扱わない。
- 反対側の傾向を身につけることを行動の目的にしない。
- 現在の傾向に合う方法、環境、判断、準備を選べる小さな提案にする。
- 実行は任意とし、能力、成果、治療・改善効果を保証しない。
- v2では冒頭の`もしよければ、`／`よければ、`を使わない。文末の`〜してみませんか。`で任意の提案であることが伝わるため、同じ意味の前置きを重ねない。
- `result-text-v1`の承認を取り消したり、過去の本文を上書きしたりしない。
